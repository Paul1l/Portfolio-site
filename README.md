# Павел Орехов — сайт-визитка

Обычный landing page / сайт-визитка на HTML, Sass и JavaScript.

## Что внутри

- `index.html` — разметка сайта.
- `scss/style.scss` — исходный Sass/SCSS.
- `css/style.css` — готовый CSS для GitHub Pages.
- `js/main.js` — меню, расчет возраста, анимации, форма email и переход в Telegram.

## Форма заявки

В форме есть два варианта связи:

1. **Отправить на email** — форма отправляет заявку на `pauletolava1804@gmail.com` через FormSubmit.
2. **Написать в Telegram** — открывает чат `@pauletolava1804`.

## Как запустить

Открой `index.html` в браузере или залей файлы на GitHub Pages.

## Как править стили

Можно редактировать сразу `css/style.css`. Если используешь Sass, редактируй `scss/style.scss`, затем скомпилируй в `css/style.css`.

Пример команды, если установлен Sass:

```bash
sass scss/style.scss css/style.css
```

Или через npx:

```bash
npx sass scss/style.scss css/style.css
```
