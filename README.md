# Павел Орехов — портфолио

Одностраничное портфолио фронтенд-разработчика в чёрно-белой гамме. На первом
экране голова из белых частиц: она собирается из облака, поворачивается к курсору
и «говорит», а под ней, как в Reels, набираются субтитры.

Сайт сделан без сборщика и фреймворка: GitHub Pages получает обычные HTML, CSS
и JavaScript-модули. Чтобы поменять текст или стиль, ничего устанавливать не нужно.

## Что есть

- голова из частиц на WebGL без библиотек (`js/modules/particle-portrait.js`);
- субтитры под головой: фразы набираются по буквам, рот двигается на гласных,
  есть кнопка паузы и повтора (`js/modules/portrait-captions.js`);
- шесть избранных работ. На экранах от 768 px превью стоят «колодой»: при прокрутке
  передняя карточка опрокидывается, следующая выходит вперёд (по мотивам Tumble Deck
  Showcase с 21st.dev, реализация своя). Кейсы открываются в окне, у каждого свой
  адрес вида `#case/meatwash`;
- услуги, как проходит работа, обо мне, вопросы, контакты и форма через FormSubmit;
- русская и английская версии без перезагрузки (`?lang=en`);
- мобильное меню с `aria-expanded`, закрытием по Escape и фокусом внутри меню;
- `prefers-reduced-motion`: голова статичная, субтитры появляются без набора. Сайт
  работает и без WebGL, и без JavaScript.

## Как устроен код

**CSS — по BEM.** Блок — самостоятельная часть страницы (`.project-card`), элемент —
часть блока (`.project-card__title`), модификатор — вариант или состояние
(`.project-card--active`, `.portrait--live`). Стили блока лежат в
`css/blocks/<имя-блока>.css`, там же его адаптив. Цвета и отступы берутся только
из переменных в `css/base.css`. Файлы подключены в `<head>` отдельными ссылками
(а не через `@import`), чтобы браузер качал их параллельно. Новый блок — новый файл
и одна строка `<link>` в нужном месте списка.

**JavaScript — модули без фреймворка.** Скрипты находят элементы по атрибутам
`data-*` (`data-captions`, `data-work-deck`), а не по классам: классы отвечают за вид,
атрибуты — за поведение, и переименование стиля ничего не ломает. Имена — полные
слова в camelCase (`scrollToProject`, `activeIndex`), константы — `UPPER_SNAKE_CASE`
с комментарием, у каждой функции JSDoc. Модули друг о друге не знают, все связи —
в `js/main.js`.

## Как запустить

ES-модули открываются только через локальный сервер:

```bash
python -m http.server 4173
```

Сайт: <http://localhost:4173/>, английская версия: <http://localhost:4173/?lang=en>.

Чтобы проверить ровно как на GitHub Pages (с путём `/Portfolio-site/`), запустите
сервер из папки уровнем выше и откройте `http://localhost:4173/Portfolio-site/`.
Пути в проекте относительные, поэтому работают оба варианта.

## Субтитры

**Как изменить текст.** Файл `js/data/caption-phrases.js`: массивы `ru` и `en`,
одна строка — одна фраза. Длинные фразы лучше не писать: на телефоне под субтитры
отведено две строки, это примерно 55 символов. Абзац для скринридеров
(`data-captions-transcript`) собирается из этих же фраз сам. В `index.html` поменяйте
первую фразу и абзац для скринридеров: их видно, если JavaScript не загрузился.

**Скорость и паузы** — константы в начале `js/modules/portrait-captions.js`:
`CHARACTER_DELAY_MS` (пауза между буквами), `PHRASE_HOLD_BASE_MS` (сколько фраза
держится на экране), `START_DELAY_MS` (пауза перед первой буквой, пока собирается голова).

Показ идёт один раз. Вне экрана и в фоновой вкладке он встаёт на паузу. Кнопка под
текстом останавливает показ, продолжает его, а в конце запускает заново.

## Голова из частиц

Портрет — `assets/head/portrait.webp` (392×542) и `portrait@2x.webp` (784×1084).
Скрипт читает яркость пикселей в масштабе показа и делает частицами самые светлые
точки (глаза, нос, губы, уши, силуэт) и часть тусклых (текстура кожи). Объём головы
придуман по контуру: это не 3D-реконструкция, у картинки нет настоящей геометрии.

Настройки — константы в начале `js/modules/particle-portrait.js`:

- `MAX_YAW` и `MAX_PITCH` — насколько голова поворачивается вбок и кивает;
- `LOOK_DISTANCE` — на каком расстоянии от головы поворот почти максимальный;
- `DESKTOP_PARTICLE_COUNT` и `MOBILE_PARTICLE_COUNT` — сколько частиц (15 000 и 12 000);
- `HEAD_PROFILE`, `FACE_LANDMARKS` и `MOUTH` — силуэт, черты лица и рот.

Если кадры идут медленно, частиц автоматически становится меньше. Вне экрана
и в фоновой вкладке анимация останавливается. При reduced motion, без WebGL или
на очень слабом устройстве остаётся статичный портрет.

**Как заменить портрет.** Если новая картинка уже из точек (белые на чёрном), впишите
голову в кадры 392×542 и 784×1084 с небольшими полями. Если это обычное фото:

```bash
python tools/portrait/make_portrait.py photo.jpg outline.json assets/head/portrait.webp
```

`outline.json` — контур головы на фото: `{"points": [[x, y], ...]}` в пикселях
(волосы, лицо, уши, без шеи). После замены проверьте `MOUTH`, `FACE_LANDMARKS`
и `HEAD_PROFILE`.

## Как добавить работу

1. Карточка — в `index.html`, внутри `<ol class="showcase__list">`. Скопируйте
   соседний `<li class="showcase__item project-card">` и поменяйте тексты и ссылки.
   Колода подхватит новую карточку сама.
2. Кейс — объект в массиве `PROJECTS` в `js/data/projects.js`. Его `slug` должен
   совпадать с `data-case-open` у кнопки «Подробнее».
3. Английские тексты карточки — в `js/i18n/english.js`, под ключами из `data-i18n`.

## Как устроены переводы

Русский текст — обычная разметка `index.html`, он же виден без JavaScript. Элементы
помечены атрибутами `data-i18n*` с ключом, английская строка лежит под тем же ключом
в `js/i18n/english.js`. Тексты, которые показывают скрипты (статусы формы, подписи
кнопок), — в `js/i18n/messages.js` на обоих языках.
