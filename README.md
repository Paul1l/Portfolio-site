# Павел Орехов — портфолио

Монохромное одностраничное портфолио frontend-разработчика. На первом экране —
голова из белых частиц на чёрном фоне: она собирается из облака, слегка
реагирует на курсор и «говорит» вместе с голосовым приветствием.

Сайт сделан без сборщика и фреймворка: GitHub Pages получает обычные HTML, CSS
и JavaScript-модули. Код можно открыть и изменить без установки зависимостей.

## Что есть в проекте

- голова из частиц на WebGL без библиотек (`js/head-particles.js`);
- голосовое приветствие: своя запись → синтезатор речи браузера → текст (`js/greeting.js`);
- реальные проекты с превью: на экранах от 768 px превью стоят «колодой» на ребре и при
  прокрутке передняя карточка опрокидывается вперёд, а следующая поднимается (по мотивам
  Tumble Deck Showcase с 21st.dev, своя реализация на CSS 3D + JS); кейсы — в модальных
  окнах с адресами вида `#case/mb-kuzbass`;
- услуги, процесс, подход, ответы на вопросы, контакты и форма заявки через FormSubmit;
- русская и английская версии с переключением без перезагрузки (`?lang=en`);
- мобильное меню с `aria-expanded`, закрытием по Escape и управлением фокусом;
- поддержка `prefers-reduced-motion`, работа без WebGL и без JavaScript.

## Как запустить

ES-модули нужно открывать через локальный сервер:

```bash
python -m http.server 4173
```

Сайт: <http://localhost:4173/>, английская версия: <http://localhost:4173/?lang=en>.

Чтобы проверить ровно как на GitHub Pages (с базовым путём `/Portfolio-site/`),
запустите сервер из папки уровнем выше и откройте `http://localhost:4173/Portfolio-site/`.
Все пути в проекте относительные, поэтому работают в обоих вариантах.

## Приветствие

Звук включается только по кнопке «Включить приветствие». Микрофон не запрашивается.

**Как изменить текст.** Откройте `js/greeting.config.js`, раздел `lines`. Каждая
строка — отдельная фраза и отдельный субтитр. Есть русская (`ru`) и английская (`en`) версии.

**Как подключить свою запись голоса.**

1. Положите файл в `assets/voice/`, например `assets/voice/greeting-ru.mp3`
   (лучше mp3 — его играют все браузеры).
2. В `js/greeting.config.js` укажите путь: `audio: { ru: 'assets/voice/greeting-ru.mp3', en: null }`.
   Путь пишется без ведущего `/` — так он работает и локально, и на GitHub Pages.
3. Необязательно: в `cues` укажите секунды, с которых начинается каждая фраза,
   например `ru: [0, 3.4, 8.1]`. Без этого субтитры переключаются пропорционально длине текста.

С записью голова пульсирует по реальной громкости (Web Audio `AnalyserNode`).

**Если записи нет**, используется синтезатор речи браузера с русским голосом. Это
голос браузера, а не ваш: на сайте так и написано — «Озвучивает синтезатор браузера».
Анимация рта в этом режиме условная, точной синхронизации с фонемами нет.
Какие голоса выбирать в первую очередь, задаёт `tts.preferredVoices`.

**Если подходящего голоса нет** или запись не загрузилась, приветствие показывается
текстом с понятным статусом. Остальной сайт работает как обычно.

## Голова из частиц

Портрет — `assets/head/portrait.webp` (392×542) и `portrait@2x.webp` (784×1084) для
экранов высокой плотности: одобренная голова из белых точек на чёрном. Браузер читает
яркость его пикселей в масштабе показа и превращает точки в частицы: большая часть —
самые светлые точки (контуры глаз, носа, губ, ушей, силуэт), остальное — тусклая
текстура кожи.
Голова «смотрит» на курсор, как портрет, который следит за зрителем: поворачивается
к нему как объём (до ~29° по горизонтали и ~15° по вертикали, кивок — вокруг шеи)
и чуть переводит взгляд. Лицо — точки портрета; к нему добавлены художественная
3D-форма по силуэту (профиль головы, рельеф носа, глазниц, губ, подбородка) и
тыльная сторона из точек — бока, затылок, макушка. У каждой точки есть нормаль:
при повороте дальняя сторона и дальнее ухо гаснут, ближняя выходит вперёд,
поэтому меняется силуэт. В покое тыльные точки скрыты, и лицо совпадает с портретом.
Это не 3D-реконструкция: настоящей геометрии у картинки нет, форма придумана по контуру.

Настройки в начале `js/head-particles.js`: `MAX_YAW` и `MAX_PITCH` — предельные углы,
`LOOK_DISTANCE` — на каком расстоянии от головы поворот почти максимален,
`GAZE_SHIFT` — насколько смещаются зрачки, `BACK_SHARE` — доля точек на тыльную
сторону, `PITCH_PIVOT_Y` — высота оси кивка, `HEAD_PROFILE` — силуэт головы.

- Пока эффект готовится, виден сам портрет; при reduced motion, без WebGL
  или на очень слабом устройстве портрет остаётся статичным.
- Частиц: до 15 000 на desktop и 6 000 на телефоне (около 18% из них — тыльная сторона). Если кадры медленные,
  их число снижается автоматически.
- Анимация останавливается вне экрана и в фоновой вкладке; потеря WebGL-контекста обрабатывается.

**Как заменить портрет.** Если новая картинка уже точечная (белые точки на чёрном),
просто впишите голову в кадр 392×542 и 784×1084 с небольшими полями и сохраните оба
файла. Если это обычное фото, сделайте точечный портрет скриптом:

```bash
python tools/portrait/make_portrait.py photo.jpg outline.json assets/head/portrait.webp
```

`outline.json` — контур головы на фото: `{"points": [[x, y], ...]}` в пикселях фото
(волосы, лицо, уши, без шеи и плеч). Подробности — в начале скрипта; скрипт пишет файл
392×542, версию 2× в этом случае можно не делать (уберите `srcset` в `index.html`).
После замены проверьте константы `MOUTH`, `FACE` и `HEAD_PROFILE` в `js/head-particles.js`:
положение рта для анимации речи, глаз, носа, бровей и подбородка для рельефа и взгляда,
силуэт головы для 3D-формы.

**Точная 3D-мимика** (настоящий поворот головы, артикуляция губ) этим способом
не делается: нужна 3D-модель головы с ригом (blendshapes для рта и глаз) и, для
синхронизации с речью, разметка фонем. Это отдельная задача.

## Как добавить проект

Карточка проекта — в `index.html` (раздел «Избранные работы»), подробный кейс —
объект в массиве `projects` в `js/projects.js` (`slug` должен совпадать с
`data-case` у кнопки). Английские тексты — в `js/i18n.js` и `projectTranslations`.

## Как устроены переводы

Русский текст остаётся в `index.html` как основной вариант и fallback без JavaScript.
Элементы помечены атрибутами `data-i18n*`, английские строки — в `js/i18n.js`
под тем же ключом. Подписи приветствия — в `runtime` того же файла.
